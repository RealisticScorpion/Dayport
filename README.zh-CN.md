# Dayport

**Your daily starting point. 每一天，从这里开始。**

一个以本地数据为主的 Chrome 新标签页：高密度导航、实用工具，以及更少的常驻标签页。

[English](README.md) · [产品设计](docs/design.md) · [路线图](docs/roadmap.md) · [参与贡献](CONTRIBUTING.md)

## 当前状态

**项目规划与仓库初始化阶段。** 当前仓库包含产品设计、拟议架构和开源协作规范。尚无可安装扩展、应用源码或正式发布版本，下列功能均为开发计划。

## 想解决的问题

常用页面不必反复翻找书签；临时需要的页面也不必一直开着。Dayport 将固定导航、自动常用和稍后继续放在同一个入口。

| 计划功能   | 设计方向                                                       |
| ---------- | -------------------------------------------------------------- |
| 高密度导航 | 紧凑分组、小图标、短标题、书签导入、键盘操作                   |
| 自动发现   | 展示浏览器最常访问；可选在本地分析近期历史，发现常用具体页面   |
| 稍后继续   | 确认选中标签页的链接保存成功后，再提供关闭操作                 |
| 自定义背景 | 本地图片、远程图片列表、约定格式的图片 API，支持定时轮换       |
| 统一搜索   | 查找导航与可选浏览器数据，切换网页搜索、ChatGPT 和 Claude 入口 |
| 日常工具   | 世界时钟、跨时区时间换算、天气和自动保存笔记                   |
| 阅读摘抄   | 导入自己的微信读书摘抄，展示原文、书名、章节和想法             |
| 数据迁移   | 导航、设置、笔记与摘抄的版本化导入导出                         |

## 页面结构

桌面默认约 70% 空间用于导航，30% 用于工具。顶部放置统一搜索和紧凑时钟；主体分为固定导航、自动常用、稍后继续；侧栏显示天气、笔记与阅读摘抄。布局随窗口宽度调整，信息密度不能以牺牲可读性和键盘操作为代价。

## 基本原则

- 固定链接的顺序由用户控制，自动推荐独立更新。
- 个人内容与历史分析默认保留在本地。
- 开启相关功能时再申请浏览器权限。
- 先读取缓存，再独立更新背景、天气等远程内容。
- 笔记与链接支持备份；导入失败时保留已有数据。
- AI 首版提供问题起草、复制和打开官方服务；首页内连续对话单独评估 API 接入。
- 微信读书先验证摘抄导入；自动同步需要另行验证登录与接口可行性。

## 参与开发

先阅读[产品设计](docs/design.md)、[架构](docs/architecture.md)和[路线图](docs/roadmap.md)。公开 Issue、PR、截图和日志中请使用合成数据。

当前文档仓库使用 Node.js 24 或更新版本和 npm；CI 使用 `.nvmrc` 指定的 Node.js 24：

```sh
git clone https://github.com/RealisticScorpion/Dayport.git
cd Dayport
npm ci
npm run check
```

`npm run format` 用于格式化文档和配置。应用构建、安装与测试说明将在引入应用代码时补充。
